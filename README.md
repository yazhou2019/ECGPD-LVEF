# ECGPD-LVEF

Official implementation of the method in the paper:

> **Detecting low left ventricular ejection fraction from ECG using an interpretable and scalable predictor-driven framework: a model development and validation study**
>
> Ya Zhou, Tianxiang Hao, Ziyi Cai, Haojie Zhu, Kejun He, Jia Liu, Xiaohan Fan, Jing Yuan

ECGPD-LVEF is an ECG-based Predictor-Driven framework for detecting low left ventricular ejection fraction (LVEF <= 45%). Instead of training another end-to-end black-box model, it reuses the diagnostic scores of conventional ECG findings generated by an ECG foundation model. The framework has two inference strategies:

- **Single-predictor approach:** each diagnostic score is evaluated independently as a predictor of low LVEF, without task-specific training on the EchoNext cohort (zero-shot-like inference).
- **Multi-predictor approach:** the 71 diagnostic scores are jointly modeled with lightweight tabular models, using Logistic regression or XGBoost.

The paper evaluates the framework on the internal EchoNext test set and an external ECG-Note cohort derived from MIMIC-IV. It further reports predictor-level interpretability, SHAP analyses, subgroup analyses, and comparisons with the official Columbia mini end-to-end baseline ([Poterucha et al., Nature 2025](https://doi.org/10.1038/s41586-025-08627-0)).

**Citation:** If you use this code, the derived predictor scores, or the reported results, please cite the main paper and the relevant upstream models/datasets. See [Citation](#citation).

## Framework Overview

- **Predictor extractor:** an ST-MEM Transformer-based ECG foundation model. ST-MEM was pretrained on Chapman-Shaoxing, Ningbo, and CODE-15%, and then post-trained on PTB-XL to classify 71 conventional ECG findings. The four ECG-only datasets contain 413,167 ECGs in total. ECG signals are standardized to 250 Hz before predictor extraction; MIMIC and PTB-XL recordings, originally sampled at 500 Hz, are resampled following the ST-MEM preprocessing pipeline.
- **Transformer and Transformer-PT:** the original fine-tuning strategy is denoted **Transformer** and follows the ST-MEM implementation ([ST-MEM repository](https://github.com/vuno/ST-MEM/tree/main)); the modified post-training strategy is denoted **Transformer-PT** and follows [arXiv:2509.12991](https://arxiv.org/abs/2509.12991). The final predictor extractor outputs 71 diagnostic scores in the range 0-1 after sigmoid activation.
- **Continuous predictor scores:** downstream LVEF modeling uses the continuous 0-1 scores rather than thresholded binary ECG diagnoses, preserving ranking information for low-LVEF detection.
- **Single-predictor analysis:** each score is used directly as an LVEF risk score. No additional training is performed on the ECG-ECHO data.
- **Multi-predictor analysis:** the 71 scores are jointly modeled using lightweight tabular models, specifically Logistic regression with an L2 penalty or XGBoost. The primary configuration, Transformer-PT-XGBoost, was selected by validation AUROC.
- **Primary outcome:** low LVEF, defined as LVEF <= 45%. EchoNext labels follow the official ECG-ECHO labeling protocol; the external ECG-Note cohort uses LVEF values extracted from clinical-note documentation.

## Scope of This Release

This release contains the code for the precomputed-predictor experiments on EchoNext and PTB-XL:

- PTB-XL evaluation of the 71 ECG findings produced by the predictor extractor.
- Single-predictor low-LVEF evaluation on the EchoNext internal test set.
- Multi-predictor Logistic regression and XGBoost training and internal-test evaluation.

Key analyses reported in the paper but not implemented by the scripts in this release:

- Raw ECG waveform preprocessing and ST-MEM predictor inference.
- Construction and evaluation of the external ECG-Note cohort from MIMIC-IV.
- SHAP, subgroup, calibration, decision-curve, predictor-count, and Columbia mini baseline analyses.

The external ECG-Note cohort construction resource is provided in the next section.

## Environment

The paper used Python 3.9, PyTorch 1.11.0, scikit-learn 1.6.1, XGBoost 2.1.4, SciPy 1.8.1, pandas 2.3.1, and NumPy 2.0.2. The saved `.joblib` models were serialized with scikit-learn 1.6.1.

Install the packages required by the code with:

```bash
pip install numpy pandas scipy scikit-learn==1.6.1 xgboost==2.1.4
```

Install PyTorch for your platform from [the official PyTorch installation guide](https://pytorch.org/get-started/locally/). PyTorch 1.11.0 follows the software environment specified by the ST-MEM repository. Using a different scikit-learn version may produce a warning when loading the provided `.joblib` models; re-training is recommended in that case.

## Usage

Run the commands from the repository root. Create the output directory first:

```bash
mkdir -p res
```

### Single-predictor analysis

```bash
python ECGPD_LVEF_Single_Predictor_patient_level.py
```

This script performs two evaluations using the precomputed Transformer-PT scores:

1. It evaluates the 71 diagnostic scores against their PTB-XL labels, with ECG-level and patient-level bootstrap confidence intervals.
2. It evaluates each diagnostic score as a standalone low-LVEF predictor on the EchoNext internal test set.

The results are written to:

```text
res/results_71preditors_patient_level.csv
```

The filename follows the output path used in the original code. The script also prints the EchoNext single-predictor AUROC, AUPRC, F1, and accuracy for each predictor.

### Multi-predictor models

Logistic regression with Transformer scores:

```bash
python ECGPD_LVEF_LR_Transformer.py
```

Logistic regression with Transformer-PT scores:

```bash
python ECGPD_LVEF_LR_Transformer_PT.py
```

XGBoost with Transformer scores:

```bash
python ECGPD_LVEF_XGB_Transformer.py
```

XGBoost with Transformer-PT scores:

```bash
python ECGPD_LVEF_XGB_Transformer_PT.py
```

Each script trains on the EchoNext training set, selects hyperparameters on the validation set, and reports AUROC, AUPRC, and F1 on the EchoNext internal test set with 95% bootstrap confidence intervals, plus accuracy at the selected threshold. The external ECG-Note evaluation is not included in these scripts.

The saved model files are:

| Model | Transformer | Transformer-PT |
| --- | --- | --- |
| Logistic regression | `saved_models/lr_transformer.joblib` | `saved_models/lr_transformer_pt.joblib` |
| XGBoost | `saved_models/xgboost_transformer.json` | `saved_models/xgboost_transformer_pt.json` |

The multi-predictor scripts print the evaluation results only. To regenerate the saved models, uncomment the corresponding `joblib.dump(...)` or `xgb_model_best.save_model(...)` line at the end of each script.

## Evaluation Protocol

- **Metrics:** the primary metrics are AUROC, AUPRC, and F1 score. The scripts also print accuracy at the selected threshold, but accuracy is not a primary metric in the paper.
- **F1 threshold:** the classification threshold is selected by maximizing F1 on the validation set and is then applied unchanged to the test set.
- **Confidence intervals:** 95% CIs are estimated from 1,000 bootstrap resamples.
- **Patient-level resampling:** for the PTB-XL predictor-extraction evaluation, bootstrap resamples are drawn by patient (`patient_id` in fold 10) to account for multiple ECGs per patient. The EchoNext validation and test sets contain one ECG per patient under the official split.
- **Held-out testing:** the internal and external test sets are used only for final evaluation. Predictor ordering, hyperparameter tuning, model selection, and F1 threshold selection use only the training and validation sets.

## Results Reported in the Paper

The main results for low-LVEF detection are reproduced below from the paper. All values are percentages, with 95% CIs in parentheses.

| Test set | Framework | Predictor extractor | Tabular model | AUROC | AUPRC | F1 |
| --- | --- | --- | --- | ---: | ---: | ---: |
| EchoNext internal | Columbia mini (official baseline) | - | - | 85.2 (83.9-86.5) | 59.9 (56.6-63.3) | 57.9 (55.4-60.3) |
| EchoNext internal | ECGPD-LVEF | Transformer | Logistic regression | 84.5 (83.1-85.9) | 56.8 (53.4-60.3) | 57.0 (54.6-59.7) |
| EchoNext internal | ECGPD-LVEF | Transformer-PT | Logistic regression | 84.9 (83.6-86.3) | 57.8 (54.6-61.2) | 58.5 (56.2-60.8) |
| EchoNext internal | ECGPD-LVEF | Transformer | XGBoost | 84.9 (83.5-86.2) | 58.5 (55.1-61.7) | 57.6 (55.1-60.1) |
| EchoNext internal | **ECGPD-LVEF** | **Transformer-PT** | **XGBoost** | **88.4 (87.1-89.5)** | **69.2 (66.2-72.0)** | **64.5 (62.2-66.7)** |
| ECG-Note external | Columbia mini (secondary comparison) | - | - | 80.8 (79.9-81.7) | 45.8 (43.7-47.7) | 47.7 (46.3-49.1) |
| ECG-Note external | **ECGPD-LVEF** | **Transformer-PT** | **XGBoost** | **86.9 (86.2-87.7)** | **57.6 (55.6-59.7)** | **53.8 (52.5-55.0)** |

The Columbia mini baseline refers to the official end-to-end model from [Poterucha et al., Nature 2025](https://doi.org/10.1038/s41586-025-08627-0).

Values in the internal-test rows are those reported in the paper; re-running the scripts may produce small differences due to library versions and hardware. The external ECG-Note rows require the external cohort pipeline and are not reproduced by this release.

The external Columbia mini comparison is secondary because five tabular features required by that model were not directly available in MIMIC-IV and were reconstructed from fiducial points provided by MIMIC-IV-ECG.

For predictor extraction on PTB-XL, Transformer-PT achieved a macro AUROC of 94.5%, AUPRC of 41.4%, and F1 of 38.3%, compared with an AUROC of 89.8% and AUPRC of 30.7% for the original Transformer. In the single-predictor analysis, NORM was the strongest individual predictor, with an internal AUROC of 81.0%, AUPRC of 47.4%, and F1 of 51.4%, and an external AUROC of 78.8%, AUPRC of 36.2%, and F1 of 42.3%. Eight predictors (NORM, ILBBB, INJAL, ISCLA, ANEUR, ISCAL, ASMI, and SVARR) achieved internal AUROCs of 71.0%-81.0%, and five maintained AUROCs of 70.7%-78.8% in the external cohort.

## Implementation Notes

- The target column is `lvef_lte_45_flag` (`use_index = 0`).
- In the single-predictor script, the `NORM` and `SR` scores are negated because higher values indicate a more normal ECG and therefore a lower risk of low LVEF. The remaining predictors are used directly.
- The EchoNext tabular matrix contains seven tabular features. The Transformer-PT multi-predictor scripts use `margin_index2 = 7` to keep the 71 appended predictor columns and discard the tabular columns; the Transformer scripts use the 71-dimensional Transformer score matrix directly.
- The preprocessing module loads both the Transformer and Transformer-PT score sets; each analysis script selects the set it needs.
- In this implementation, Logistic regression uses L2 regularization with `C` selected from `{0.001, 0.01, 0.1, 1, 10}`. XGBoost uses `n_estimators=1000`, early stopping after 30 rounds, `max_depth` selected from `{3, 5, 7}`, and `learning_rate` selected from `{0.05, 0.1, 0.2}`. Both models are selected by validation AUROC.
